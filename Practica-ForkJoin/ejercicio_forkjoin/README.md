# Word Count Concurrente

Este algoritmo está diseñado para procesar múltiples archivos `.txt` de gran tamaño y ejecutar un conteo de palabras (*word count*) de manera eficiente.

## Dataset y Pruebas

Debido a su gran tamaño, los archivos de texto utilizados para el procesamiento no se incluyen en este repositorio. 

Para replicar el entorno de pruebas, descargar un archivo de por lo menos $4$ GB. Por ejemplo, desde el siguiente enlace y coloca los archivos extraídos dentro de una carpeta local llamada `data/`:

* [Descargar Dataset: Wikipedia TXT Spanish (Hugging Face)](https://huggingface.co/datasets/davidquicast/wikipedia-txt-spanish)
