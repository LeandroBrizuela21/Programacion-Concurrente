# Enunciado
Realizar un pequeño utilitario que utilizando el **crate** `reqwest` imprima por pantalla los nombres de las canciones de los nuevos albumes releaseados en **Spotify**.

## Documentación
- [Spotify Web API: Get New Realeases](https://developer.spotify.com/documentation/web-api/reference/get-new-releases)
- [Spotify Web API: Get Album's Tracks](https://developer.spotify.com/documentation/web-api/reference/get-an-albums-tracks)
